This repo is made for me to implement classes for general coding practice in C++;

The following are currently planned, starting with standard library classes for better reference:

1 - std::unique_ptr (Warm-up: templates, custom deleters, move-only semantics)

2 - std::vector<T> (Raw memory allocation, placement new, exception safety)

3 - std::shared_ptr / std::weak_ptr (Atomic ref counts, control block design)

4 - std::function (Type erasure, function signatures, SBO)

5 - std::pmr::monotonic_buffer_resource (Memory alignment, zero-overhead arena allocation)
